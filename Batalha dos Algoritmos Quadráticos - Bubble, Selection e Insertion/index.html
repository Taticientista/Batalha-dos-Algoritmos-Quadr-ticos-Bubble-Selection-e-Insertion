🎯 Objetivo

Executar os três algoritmos sobre cópias idênticas de vetores e relacionar a análise assintótica com medições práticas. O projeto não presume um vencedor: as conclusões devem ser baseadas nos resultados coletados.

🫧 Bubble Sort

Compara elementos adjacentes e pode interromper cedo quando o vetor já está ordenado.

Melhor caso: O(n)
Pior caso: O(n²)

🎯 Selection Sort

Seleciona o menor elemento restante e o posiciona na próxima posição.

Comparações: O(n²)
Trocas: até n − 1

📥 Insertion Sort

Insere cada elemento na posição correta dentro da parte já ordenada.

Melhor caso: O(n)
Pior caso: O(n²)

🧪 Como executar

Com GCC ou Clang, Make e Python 3 instalados:

make
make test
./build/benchmark --help

Consulte o README para as opções de benchmark, geração de CSV e análise dos resultados.

📊 Resultados experimentais

Os resultados dependem do hardware, compilador, flags de compilação, tamanho e distribuição dos dados. Registre e compare as medições reais em vez de preencher números estimados como se fossem resultados observados.

Este site é uma página de apresentação. A metodologia, os comandos completos e a tabela para registrar resultados ficam no README.md.

📁 O que o projeto mede

Comparações

Quantidade de comparações entre chaves durante a ordenação.

Movimentações

Escritas, deslocamentos ou trocas conforme a instrumentação adotada.

Tempo

Duração medida e registrada para comparar execuções sob as mesmas condições.
